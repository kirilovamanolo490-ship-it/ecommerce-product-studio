# 无品牌流程示例

真实商品制作效果请看 [C200 案例图册](../docs/showcase/c200-v3/README.md)。

此目录用于试跑数据协议和本地画布，不包含客户资料、品牌商品原图、生成成品或真实性能宣称。方格图由代码绘制，明确不是商品照片。

## 结构示例 `planning-only/`

包含完整四份任务 JSON、一张 128×128 方格示意和说明文本。示意中只有一张主图计划、没有详情页，目的是展示字段与引用关系。

在仓库根目录运行：

```sh
python3 .agents/skills/ecommerce-product-studio/scripts/project.py validate examples/planning-only
```

应返回 `0`。这证明协议结构可以通过，不证明该输入可直接进入真实商品制作。演示中 `real_photo` 仅展示合法枚举值；校验器不会识别方格图是否真实商品照片。实际任务必须使用真实产品参考并人工核对。

不要把这份示例的 `supported` 宣称迁移为真实商品事实。请用 `init` 建立自己的任务，再按资料填写。

## 原生画布示例 `editor-demo.json`

这是独立的 yft/Fabric `Template[]` 工程，有两页。每页包含背景、两个文字对象和一张嵌入式 PNG 图片，图片不依赖外网 URL。

1. 按[编辑器 README](../apps/editor-yft/README.md)启动本地服务。
2. 通过“打开项目 JSON”打开此文件；已有画布先保存。
3. 双击标题改字，替换方格图片，切页再返回。
4. 保存整个项目到新文件，关闭页面后重新导入。
5. 核对两页内容与顺序，再导出当前页 PNG。

只有实际完成这些操作才能报告本机编辑闭环通过。两页工程的 JSON 格式与分镜 JSON 不同，二者没有自动转换关系。

## 素材与修改

方格是技术占位，放大只用于观察对象，不代表可交付图片质量。可自行替换图片、文字和尺寸进行练习；真实素材放在被忽略的 `products/<编号>/` 中。正式交付要求见[验收与交付](../docs/quality-and-delivery.md)。
