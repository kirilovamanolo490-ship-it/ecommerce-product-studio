# 主图的元素语法与提示词编排

用于中文店铺营销主图、商品海报组，或用户反馈“太素、认不出品类、缺电商设计”的改稿。先按图的用途设计信息架构；具体平台上传规范另行核对。这套方法不规定所有商品都要九张，也不把某种边框、字号或产品出现次数当通用审美标准。

## 先选用途，再选画面

- **营销封面**：帮助列表浏览者认出品类、商品身份和最值得继续看的理由。通常同时需要清晰商品、品类/名称、一个核心用途或利益，以及少量已核实的支持信息。
- **商品目录首图**：承担实收商品识别；当用户要求无字图或目标槽位明确要求纯商品时采用。它可与营销封面分别保存，不自动替代用户要的宣传封面。
- **图库辅图**：逐页补足一个购买判断，用场景、操作、细节、关系或规格帮助理解。
- **详情模块**：展开机制、步骤、条件和选择；重复主图主题时增加信息或证据。

用户提到淘宝/天猫作为视觉参考，不等于已选定最终发布站点。仍可先设计中文营销稿；不把 Amazon 白底规则或上游固定张数当作这个稿子的创意策略。

## 一张图的六类元素

| 语义角色 | 回答什么 | 常见可执行元素 |
|---|---|---|
| 商品身份 | 卖什么、哪个型号 | 商品照片、品类名、品牌/型号、SKU或数量 |
| 核心主张 | 为什么值得看 | 一句用途/利益/差异标题；只设一个第一阅读重点 |
| 视觉依据 | 主张凭什么成立 | 操作关系、可见细节、已核实规格、真实来源素材；氛围照片不充当测试结果 |
| 支持信息 | 还有什么值得知道 | 与主张有关的短标签、参数、解释；多条信息组成次级组 |
| 决策条件 | 是否适合我、要准备什么 | 尺寸、供电、兼容、卡另购、上限与环境条件等 |
| 视觉组织 | 怎么一眼读懂 | 色块、标题底衬、角框、分栏、引线、图标、留白和文字强调 |

每个元素都写 `purpose`：它帮助买家形成哪个判断。没有作用的标签/装饰删掉；缺少身份或购买理由时补足。可重用一套色光、字体角色和图形语言，但不同页面应由各自任务决定骨架。

品牌已知时，先检查用户素材和官方公开来源中的正式Logo、已确认口号与品牌应用，再锁定品牌区。记录官方资产原文件、来源、适用版本/底色和实际可确认的颜色；不要把普通字体品牌名当正式字标，也不要让图像模型仿画已有Logo。型号、品类文字与Logo分层，机身原有标识不改。未找到公开VI规范时，本项目延展的图标、色面、边框和字库应标为自行设计，不能冒称官方规则；其他SKU奖项或能力也不能迁移。

边框和色带可组织版面、分组卖点、提高文字对比和系列识别。不要全禁装饰，也不要每页都套同一个页头/底框。装饰是一种组织手段，既不代替卖点，也不证明品质。

## 先排购买路径

先认品类和价值，再代入使用场景，再解释理由/操作，最后处理适配与实收疑问。复杂产品可以提前适配条件；风格商品可提前外观/搭配。首图、场景、微距、参数的顺序必须能解释。

同一商品可多次出现，只要它分别服务识别、尺度、操作、结构等任务。不要为了避免重复而规定“整机只能出现两次”，也不要为了变化而编造背面/内部或随机换镜头。特写需要支持实际购买判断；镜头放大本身不证明视频分辨率。

每页 brief 至少写：`buyerQuestion`、`takeaway`、`elements + purpose`、`readingOrder`、`evidence`、`transition`。用商品事实决定页数，不先列九个参数再分配九张。

## 从 brief 编译成三份执行规格

1. **完整构图提示**：写本页任务、准确文案、主次、元素位置关系、产品与场景、文字与图形的组合。用于判断完整设计方向。
2. **视觉素材提示**：写摄影/背景/场景/纹理、必须保留的产品特征和实际文案区域；图像工具生产对应素材。原图、构图参考、光线参考各自说明用途。
3. **可编辑排版规格**：精确文案、图形、字体角色、标签、参数线和图片对象。以真实画布渲染后核对；提示 JSON 不等于母版。

三份规格属于同一个构图候选：商品在左/右、文案区域、景别和主次不能各说一套。“素材阶段不生成文字”只决定文字的制作方式，不能因此遗漏完整方案中的字形、标题组合、标签或图形装置。营销方案须写清具体的视觉组织方式；选择不加外框时，也要说明用什么对齐、色面或层级完成分组。

可使用归一化 `[left, top, right, bottom]` 区域提出布局。候选 bbox 是设计建议；批准的文字、安全区和真实商品边界才锁定。背景、装饰与主体可有目的地重叠，不采用“任何重叠都失败”的检查。

### 内容和关系约束

- 事实有来源，产品身份/SKU/数量/标识一致，中文准确。
- 营销封面的商品身份、品类和主要用途/购买理由不能同时缺失。
- 主标题视觉从属关系明确；支持标签不能和标题全部同字号/同权重。
- 图形的承托、分组或方向作用明确；引线指向正确目标。
- 文字不遮关键产品部件；复杂图像上给文字可读的承托或位置。
- 买家需要的条件紧邻有关主张；页码、生成过程、审查说明留在内部账本。
- 未提供的价格、折扣、赠品、认证、销量、保障不生成，也不以“福利/信任”空占位。

### 风格目标

写成具体选择：品牌色如何分配、标题字形/字重/分行、重点词怎样强调、产品和标题如何互相平衡、光源和材质如何可信、框架怎样与主体结合。仅写“高级、简约、商业化”不够。不要把不明来源的转化率或自评分当验收标准。

## 验收分两层

结构检查能发现字段缺失、引用不存在、文字越界、错误遮挡或元素关系冲突。视觉检查还要实际看：列表缩略图先读到什么、手机宽度是否读懂、产品是否真实、主张和画面是否对应、装饰是否有用、相邻页是否有新增判断。自动检查和事实准确都不能代替商业视觉判断。

先将首图与一张承接辅图做成完整方向，再扩展有依据的套图。用户已授权完成制作时，继续自主质检与修订；不要把此顺序变成重复审批门。
