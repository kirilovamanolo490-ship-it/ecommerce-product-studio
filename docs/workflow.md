# 从商品素材到可编辑交付的核心流程

每个阶段都要留下可复查的文件。一个命令成功、一个目录存在或一张图生成，都不能代替后续阶段的验证。

## 1. 接收素材与确认范围

**输入：**真实商品照片、商品名称；可选说明书、参数表、品牌文件、已有文案、目标平台/站点/语言。

建立独立任务，保留源图副本与哈希。逐图查看清晰度、视角和真实配件；说明书按具体型号和硬件版本核对。记录资料中的冲突，不混用外形相似的其他 SKU。真实照片、官方规格、用户提供信息和设计推断分别标记。

**输出：**`input/` 和 `product.json.sources`。完成条件是资料可读、型号可识别、缺口已记录；初始化脚本只做后缀与非空检查，不能承担图片解码验收。

## 2. 建立商品事实与身份约束

从真实图片记录轮廓、比例、颜色、标识、接口、配件数量和已知视角，写入 `identity_lock`。把可用于页面的事实写入 `claims`，每条绑定来源 ID 和页码/原句位置。可见颜色不能被改写成未经证实的材质；宣传句不自动等于检测证据。

- `supported`：对照具体来源核实，可供页面引用。
- `pending`：证据不足，保留在档案里等待核对。
- `conflicting`：资料互相冲突，需要解决后才能使用。

**输出：**可追溯商品档案。完成条件是每个计划使用的事实都能回到相应资料，不靠语言模型补出性能。

## 3. 规划购买顺序与页面任务

先写商品定位、目标人群和前三个有证据的购买理由，再分配页面。可参考“识别 → 用途 → 理由 → 证据 → 使用 → 适配 → 清单 → 顾虑”，但顺序由具体商品决定。

每页至少回答：买家在问什么？只记住什么结论？画面凭什么支持它？哪些文案会显示？引用哪些来源？采用实拍、参考生成还是混合方式？

主图不超过 9 张，不必凑满。详情没有固定数量；重复主图主题时必须增加解释、证据或条件。营销封面、目录白底首图、图库辅图和详情模块是不同任务，不能拿一张通用图替代所有槽位。

**输出：**`storyboard.json`。完成条件是页数合理、顺序可解释、每页有新增判断，且结构校验通过。

## 4. 锁定风格与先行页面

在 `style.json` 记录色彩、字体角色、标题与正文层级、安全区、摄影光线、道具、产品比例和禁止漂移项。把“高级”“有质感”转成可执行选择。

先做主视觉和一张信息页，检查商品识别、真实感、文案层级和手机阅读。用户已授权完成整套时，按内部检查继续推进，无需将每个步骤变成审批。阅读[主图设计语法](../.agents/skills/ecommerce-product-studio/references/main-image-design-grammar.md)确定元素作用和阅读顺序。

**输出：**统一风格与可扩展的页面方向。完成条件是设计方向实际可见，而不是只有提示词。

## 5. 制作视觉资产

明确当前图像工具的实际服务路由。输入真实产品参考，记录生成日期、输入引用、提示词、输出资产和修正记录。背景、场景与局部视觉修复使用图像工具，准确标题、参数、尺寸线与脚注留到排版层。

没有对应资料时，不生成背面、内部或拆解结构来充当商品证据。场景演绎、功能示意不能伪装成监控实拍、测试对比或真实评价。发现产品形变只修受影响资产，保留已合格部分。

**输出：**`assets/` 中独立的产品/背景/场景资产及生成记录。完成条件是图像实际存在，并与真实商品及页面目的相符。

## 6. 进入可编辑母版

按策划手动排版或编写针对本商品的转换器，建立编辑器原生页面。至少保持背景、商品图片、标题、正文、标注和脚注的独立对象；页面与对象 ID 稳定，便于局部改稿。

`product.json` 是事实，`storyboard.json` 是计划，原生 Template[] 才是画布母版。没有通用编译器时，应明确保留这个制作步骤，不声称分镜可以直接一键导入。

图片优先用嵌入 data URI 或随工程打包的稳定资源。临时 URL、开发机路径和 `blob:` URL 不能作为可靠交付。文字使用有权使用、接收端可取得的字体，并检查替代字体后的换行。

**输出：**`masters/` 中可打开的实际工程。完成条件是文字与图片确实可独立选择修改，而不是把整页 PNG 放入画布。

## 7. 全套质量与编辑闭环检查

按[验收规范](quality-and-delivery.md)检查完整图组、手机阅读、原图对照、尺寸、语言和版面。然后用真实界面完成改字、换图、切页、整套保存、关闭、重开和导出。

失败时回到最小受影响阶段：错字改文字，错误参数回查事实，背景不合适替换资产，产品身份漂移重新制作有关视觉。修改后的页面与整套一致性都要复检。

**输出：**`qa/` 记录和修正后的成品。结构通过、视觉通过、编辑通过分别记录，不自动互相替代。

## 8. 交付与后续发布

交付母版、资产、导出图、分镜和事实记录、验收说明。标注图像是否示意、哪些素材不可独立分层、所用字体、导出尺寸和未核验条件。

若随后要上传电商平台，应重新核对平台、站点、类目、首图、图数、文字、比例、文件大小和详情切片要求，再另行执行发布。仓库公开发布与电商上架是不同动作，本核心流程不含自动上架功能。
