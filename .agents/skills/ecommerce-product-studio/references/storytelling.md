# 商品图与详情页的叙事规划

这份参考用于规划商品视觉内容，不是自动生成好的成品，也不规定每个商品都采用同一套页数或顺序。先弄清买家在浏览时要做哪些决定，再安排图片回答问题。每一页应承担一个主要购买决策问题；如果一页同时讲太多事情，或相邻几页重复同一卖点，就拆分、合并或删除。

## 主图与详情页怎样接力

主图负责让买家快速辨认商品、理解最值得继续看的理由，并帮助其决定是否点开或继续浏览。营销封面通常需要商品身份、品类、明确用途/利益和少量支持信息；纯商品照片适用于用户要求无字或目标槽位已核验有此需要的目录首图。是否能叠字与实际上传比例按目标平台和类目规则核实。主图组数量不超过 9 张，但具体数量应由商品信息量、素材质量和平台要求决定，不必凑满。元素与层级的执行方法见 [main-image-design-grammar.md](main-image-design-grammar.md)。

详情页接住主图留下的疑问，补上理解、比较和下单所需的信息。它可以展开主图的核心理由，也可以补充主图没有空间回答的适配条件、组成、尺寸、使用方法、限制或证据。主图讲过的卖点若在详情页再次出现，应增加新的解释、实物细节或证据，而不是只换句说法。若详情页含有独立于主图组的长图模块，数量和次序按商品、证据与平台展示方式安排，不预设固定模块数。

把整套内容视作一条可重排的决策路径：先让人认出“这是什么”，再解决“它是否适合我、凭什么相信、怎么买或怎么用”等真实疑问。并非每个商品都要回答所有问题；没有意义或没有证据支持的段落就不做。每张图的主结论应可单独理解，同时和前后页形成递进。

## 按品类调整顺序

- **颜值或风格驱动**：优先呈现商品整体、质感、比例和真实使用氛围，再补材质、颜色、尺寸、搭配或维护信息。场景只能帮助感受，不能暗示未经证实的性能。
- **功能或问题驱动**：先让买家看懂用途和操作，再讲作用机制、适用条件、实际表现与限制。前后对比只有在素材和条件足以证明差异时才使用；缺少证据时改用步骤图、结构说明或中性场景，不要硬凑效果对比。
- **参数或规格驱动**：先说明关键参数对选择有什么影响，再给规格、兼容范围、型号差异与购买核对方式。参数应能追溯到包装、说明书或用户提供的资料；不要把推测写成性能结论。

混合品类可以组合这些路径。排序由最先阻碍购买的疑问决定，不由“颜值/功能/参数”标签自动决定。换序后复核整套图：首图承诺能否被后续信息兑现，关键限制是否在买家需要作决定前出现。

## 逐图 Brief 字段

每张计划图用一条 brief 描述；按需要补充字段，不要求为了填满表格而造内容。

| 字段 | 写法 |
|---|---|
| 页码 / 画面角色 | 如识别商品、建立兴趣、解释差异、展示证据、说明规格；角色是当前这页的任务，不是固定页名。 |
| 买家问题 | 用买家的具体疑问表达，一页聚焦一个主要问题。 |
| 结论 | 看完后希望买家理解的单一答案；缺资料时标“待确认”，不要替产品编结论。 |
| 视觉证据 | 哪个真实细节、参数、文件、场景或操作过程支撑结论；标明来源或素材位置。 |
| 可见文案 | 仅写画面上必要的标题、标签、注释和条件；没有必要时写“无叠字”。 |
| Claim IDs | 填入对应的宣称编号，便于追溯来源、状态和允许表达；没有事实型宣称时留空。 |
| 所需素材 | 列明需提供或拍摄的角度、细节、包装、说明书、尺寸图、场景等。 |
| 生成 vs 真实图 | 标明哪些内容用生成图、排版或示意图，哪些必须来自真实照片/文件；不得让生成图冒充实物、检测或用户案例。 |
| 移动端层级 | 写明缩小到手机展示时的第一落点、次级信息和可删减细节；核心信息应清楚，条件与限制不能被小字藏起。 |

## 证据与画面边界

一张源照片只能证明它实际拍到的内容。若照片只展示正面，不得据此编写背面结构、接口、配件、材质细节或包装清单；相应内容应索取新角度、查验可靠资料，或标作待补。生成画面可用于氛围、抽象背景和明确标注的示意，不可补造具体商品细节或将虚构效果包装成实拍。

把关键事实与 Claim ID 对应起来，再决定文案和画面能否表达。缺少对比基准、相同拍摄条件、可验证结果或其他必要证据时，不制作“使用前/使用后”对比，也不通过箭头、色差或构图暗示已证实的效果。可改成真实操作步骤、参数说明或不作效果判断的场景图。

最后检查每页是否只回答一个主要问题、证据是否支撑结论、前后页是否各有新增信息、缩小后是否仍读得懂。检查的对象是规划稿；brief 完成不代表图片已生成、已核实或可以直接发布。
