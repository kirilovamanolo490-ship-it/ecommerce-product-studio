# 公开范围、来源与素材边界

本仓库公开可复用的工作方法、档案工具、编辑器本地修改和演示，帮助读者自行组织合法取得的商品素材。

## 纳入版本管理

- 根 README 与项目操作约定。
- `.agents/skills/ecommerce-product-studio/` 的技能、方法、数据协议及 CLI。
- `docs/` 的操作与验收文档。
- `products/README.md` 的真实任务入口说明。
- `examples/` 的自制占位示意和画布演示。
- `scripts/setup_editor.py` 的固定版本重建脚本。
- `apps/editor-yft/` 中的使用说明、历史技术记录、上游 README、许可证、来源记录和源码覆盖文件。

## 留在本地

`Product/` 品牌研究素材、商品原图、说明书、生成图、工程大文件、客户/商品任务、`github/` 第三方研究快照、`research/` 原始过程记录、`workspace/` 运行目录，以及依赖缓存、`.env`、账号凭据和构建输出不随核心仓库上传。

`.gitignore` 使用公开入口白名单，具体商品默认忽略。以后新增公开文件时先检查内容，再加入版本管理；不要为了提交方便强制添加整个本地目录。忽略规则不是凭据检测器，已跟踪文件的改动仍需正常检查。

本地案例 README 也已补充，但由于其链接依赖未公开商品资产，它们留在本地，与公共操作文档分开维护。第三方快照内部 README 不改写成我们自己的项目说明。

## 编辑器来源与重建

- 上游：[dromara/yft-design](https://github.com/dromara/yft-design)。
- 固定 commit：`f1328edcd07373267bc372bab19be466c7482fc3`。
- 上游许可证：[MIT 原文](../apps/editor-yft/LICENSE)。
- 归档 URL 与 SHA-256：[UPSTREAM.json](../apps/editor-yft/UPSTREAM.json)。
- 本地改动：[overrides](../apps/editor-yft/overrides)；包括本地文件导入、整套工程保存/重开、切页同步和相关修复。

重建脚本从该固定上游版本下载完整源码，验证归档 SHA-256，检查解压路径和文件类型，再应用公开覆盖文件。它不会自动安装依赖、运行上游部署脚本或上传文件。目标已有内容时拒绝覆盖。

完整上游源码中的字体、图标、图片和依赖会在下载后保存在你自己的运行目录，公开核心仓库不重复分发这些资产。代码许可不应被理解为所有品牌、字体或商品素材均获统一商用授权。

锁文件保留实际版本与来源，包括 `registry.npmmirror.com` 的包下载地址。`npm ci --ignore-scripts` 使用锁文件并跳过依赖生命周期脚本；它不等同于对依赖做了安全审计。切换镜像或升级版本属于后续维护，应重新安装并复验编辑闭环。
