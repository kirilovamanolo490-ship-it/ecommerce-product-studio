| 文档 | 解决的问题 |
|---|---|
| [quickstart.md](quickstart.md) | 安装什么、从哪个目录执行、怎样初始化和启动编辑器 |
| [workflow.md](workflow.md) | 每个环节的输入、动作、输出与完成条件 |
| [data-contract.md](data-contract.md) | 四份任务 JSON 的字段、引用关系和校验范围 |
| [quality-and-delivery.md](quality-and-delivery.md) | 怎样检验整套视觉、原生编辑、导出和交付 |
| [publication.md](publication.md) | 公开文件范围、第三方来源、任务素材与许可边界 |
| [verification.md](verification.md) | 本次实际运行检查与尚未验证的能力 |

商品任务位置见 [products/README.md](../products/README.md)；画布操作见 [apps/editor-yft/README.md](../apps/editor-yft/README.md)；可运行示例见 [examples/README.md](../examples/README.md)。
